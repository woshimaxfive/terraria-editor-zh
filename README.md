# 泰拉瑞亚中文网页编辑器

以 TEdit 的 C# 世界、编辑和绘图代码为基础，通过 .NET WebAssembly 和 Avalonia Browser 在浏览器中运行。首发支持 Windows 上的 Chrome 和 Edge，无需安装桌面编辑器。

打开本机 `.wld`；模组世界同时选择对应 `.twld`。编辑后下载副本。世界、配对文件、历史和本机备份在浏览器本地处理；清理站点数据会清除本机备份。需要跨设备或长期保管时，请下载文件。

完整游戏纹理由用户从自己的 Terraria 安装中选择，项目不分发游戏纹理。没有导入游戏资源时仍可使用颜色地图。首次完整加载后，运行资源可由浏览器保存以便离线使用。

## 基本操作

打开 `.wld` 文件即可编辑，也可先创建练习世界熟悉操作。地图下方提供平移、缩放、适应全图和回到出生点；中键拖动或空格加左键拖动也可平移，滚轮以鼠标位置为中心缩放。

选择材料后，顶部显示当前材料和掩码，右侧提供颜色色块与材料预览。笔刷拖动时显示临时轨迹，松开后按工具、掩码和选区计算整笔结果；一次撤销对应一笔。

“保存本机进度”用于在当前浏览器恢复编辑；“下载世界文件”用于取得可放回游戏存档目录的文件，界面分别显示两种状态。选色窗口可预览颜色，再点击“应用”保留，或点击“取消”恢复打开前的颜色。

## 使用范围

提供原版世界编解码、绘图工具、对象和世界属性编辑、建筑模板、撤销重做、原版脚本接口、贴图预览及图片/地图图块导出。支持本机进度、历史备份和配对文件下载。

首发适配 Windows 电脑上的 Chrome、Edge。标准大世界最多 8400×2400；世界与配套输入合计、单个模板文件以及编码后的单次图片/图块包上限各为 256MiB。大图片采用原版分条绘制，文件达到上限时请分区导出。当前活动模板与本机模板库分别保存；本机模板库最多 32 份、合计 128MiB，浏览器站点配额仍然适用。

恢复包最多 256MiB、展开数据最多 1GiB；接近历史容量时，无法安全保存的新操作会被拒绝并回滚。保存到本机不能替代下载备份。

模组世界须同时打开同名 `.wld` 和 `.twld`，并保留原始副本。导出沿用原版模组编解码器；模组裁剪和扩展继续保护性禁用，以免丢失不透明的模组坐标数据。手机、Safari 和 Firefox 尚未作为支持平台验证。

## 本地处理和离线

世界、玩家存档、模板、贴图及编辑历史由浏览器在本机处理，不上传到编辑服务，不设远端存档数据库。GitHub Pages 仅分发网页与运行资源；首次加载和检查更新需要联网。浏览器清理站点数据可能删除进度、备份和离线缓存。关闭所有本站页面后重新打开，才切换至已经缓存完成的新版本。

这是独立的非官方社区项目，与 Re-Logic、Terraria 或 TEdit 官方没有隶属关系。游戏内容归其权利人；使用者自行选择有权使用的游戏资源。

## 从源码构建

安装 .NET SDK 10.0.403、对应 WebAssembly 浏览器工具链、Python 3。首次安装工具链运行 `dotnet workload install wasm-tools --skip-manifest-update`，沿用该 SDK 自带的清单。直接包版本写在项目文件中；普通应用构建使用随源码附带的浏览器模块，不需要运行 npm 安装脚本。

```powershell
pwsh ./scripts/build.ps1
```

输出 `dist/` 是纯静态文件，可部署至支持 HTTPS 的静态站点或 GitHub Pages。保留整个目录结构，包括根 Service Worker、`core/`、`ui/` 及第三方声明。使用本地 HTTP 服务器预览，不能直接双击 HTML 文件运行。
