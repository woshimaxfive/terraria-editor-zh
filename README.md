# 泰拉瑞亚地图编辑器

[访问网页](https://woshimaxfive.github.io/terraria-editor-zh/)

一个独立实现的泰拉瑞亚网页地图编辑器，目前提供地图浏览和基础方块编辑。

## 当前功能

- 在本机浏览器中打开 `.wld`，查看世界名称、尺寸、种子、出生点、难度和对象数量。
- 浏览色块地图，支持拖动、滚轮或双指缩放、坐标查看、全图与出生点定位。也可聚焦地图后使用方向键、+ / − 和 Home。
- 画笔支持泥土、石块、木材、灰砖和玻璃，尺寸为 1、3、5、9 格；放大到 200% 以上后绘制，每次拖动作为一步操作。保留墙壁、液体、电线和原有方块状态，跳过家具等依赖帧数据的特殊图格。
- 吸管可读取方块 ID，选取上述 5 种材料后自动切换到画笔；空格、特殊图格或尚未支持的材料会提示原因，不改变材料或历史记录。放大到 200% 以上点击使用，拖动或双指浏览不会取色。
- 橡皮与画笔共用尺寸、笔画预览和撤销历史，只擦除方块；清除该方块的涂料、坡度、制动器等附属状态，保留墙壁、液体与电线。为保护家具及其支撑，跳过特殊图格和与其直接相邻（含斜邻）的方块。
- 撤销与重做，可使用按钮或聚焦地图后按 Ctrl+Z / Ctrl+Y（也支持 Ctrl+Shift+Z）。Esc 取消尚未完成的笔画，触控第二指加入时也会取消该笔并切换为浏览手势。
- 导出世界副本：未编辑时要求重新生成的文件与原文件逐字节一致；首次编辑前检查相同的保真条件，修改后核对世界头、箱子、NPC 等非图格区段及区段位置变化，存在异常时停止导出。
- 首次成功缓存网站后，可以断网打开、编辑与导出文件。存档不会上传，也不会写入网站离线缓存；关闭或刷新页面后需要重新选择文件。存在未导出修改时提示确认，但浏览器被系统终止时无法保证提示生效，请及时导出。

当前读取范围为文件格式版本 194–326，且受上游解析器的标准世界尺寸限制。格式范围不代表所有存档均经过游戏验证。地图为基础色块显示，尚未显示游戏贴图、帧变体、油漆、电线、坡面和完整家具效果；缩小时使用采样，放大可查看单格。编辑仍处于早期阶段，暂不支持框选、家具、箱子物品编辑或 `.twld` 模组配套文件，游戏内兼容性仍需实际验收。单笔最多 10000 格；历史最多保留 100 步且累计不超过 50000 格修改记录，超过时释放最早的步骤。请保留原始存档，使用更新的浏览器并先测试副本。

## 本地运行

使用 Node.js 22.12 或更新的兼容版本：

~~~sh
npm ci
npm run dev
~~~

构建：

~~~sh
npm run build
~~~

测试：

~~~sh
npm test
~~~

测试首次运行会下载固定上游提交的 7 个世界样例，并验证 SHA-256。样例只保存在本地忽略目录中，不会打包到网站。

项目子目录部署时设置 VITE_BASE_PATH=/仓库名/，仅需托管 dist/，无需服务器端程序。

## 开源来源

文件格式与功能研究参考 [TEdit](https://github.com/TEdit/Terraria-Map-Editor) 和 [TEdit Web](https://github.com/TEdit/terraria-map-editor-web)。世界文件读写通过项目适配层接入 [terraria-world-file-ts](https://github.com/TEdit/terraria-world-file-ts)，固定来源和局部修改见 [vendor/terraria-world-file](vendor/terraria-world-file/README.md)。完整世界留在 Worker 中处理，界面接收基本信息和当前视图的像素数据。

静态资源缓存、构建支持与地图颜色数据沿用并适配此前基于 TEdit Web 的实现；颜色来源见 [vendor/tedit-map-colors](vendor/tedit-map-colors/README.md)。复用部分保留原有许可与署名，详见 [开源声明](public/THIRD_PARTY_NOTICES.txt)。新增代码采用 [MIT 许可证](LICENSE)。
