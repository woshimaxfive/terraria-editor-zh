# 泰拉瑞亚地图编辑器

[访问网页](https://woshimaxfive.github.io/terraria-editor-zh/)

一个独立实现的泰拉瑞亚网页地图编辑器，目前提供地图浏览、普通方块、墙壁与液体编辑、普通图格区域复制粘贴及建筑模板。

## 当前功能

- 在本机浏览器中打开 `.wld`，查看世界名称、尺寸、种子、出生点、难度和对象数量。
- 浏览色块地图；可从本机选择 Tiles_0、1、2、3.xnb 或同名 PNG，在显示面板切换基础地形贴图。资源只在本机读取，关闭世界即释放，不分发游戏图片。支持拖动、滚轮或双指缩放、坐标查看、全图与出生点定位。也可聚焦地图后使用方向键、+ / − 和 Home。
- 编辑工作区采用顶部文件/编辑/图层/帮助菜单、上下文参数、左侧工具、右侧材料/建筑/世界/显示/帮助面板和底部状态栏。菜单支持方向键、Home/End 和 Esc；手机侧边面板浮动展开，切换面板不挤压地图。
- 材料目录包含 139 种普通方块和 50 种建筑墙壁，支持中文名、英文名、ID 搜索和分类筛选；搜索没有结果时保留当前材料。目录按已验证范围逐步开放，尚未包含所有游戏材料。
- 在编辑图层或材料面板选择液体，可绘制水、熔岩、蜂蜜和微光；液量采用桌面原版 0%–100% 的 11 档，默认满量，0% 清除液体。支持画笔、选区填充、橡皮、选区擦除、吸管及撤销重做，只修改液体种类和液量。吸管按原版向上取最近档位。格式 269 以下不支持微光；跳过特殊家具和实体附近图格。显示使用基础色彩，不模拟游戏内液体流动、反应或家具破坏。
- 电线图层可多选红、蓝、绿、黄：画笔添加选中色线，橡皮只移除选中色线，其他颜色和所有材料字段保持不变。支持连接家具和机关、选区、吸管及历史。制动器图层独立设置是否有制动器及是否虚化，仅作用于已有方块；橡皮同时移除制动器并实化。选择对应编辑图层自动显示标记，放大至 200% 以上绘制简化连线与状态标记，显示面板可分别关闭；不分发游戏贴图，也不在网页模拟电路。
- 坡形图层可设置完整方块、半砖和四向斜坡，只作用于原版支持坡面的已有方块（含平台），橡皮恢复完整方块。涂料图层可分别设置方块/墙壁的 32 种油漆或隐形/全亮涂层，支持家具染色、吸管、选区和历史，保留帧和实体；橡皮只清除当前类型。旧格式禁用涂层，夜明涂料在格式 269 起转换为全亮涂层。放大时显示简化坡形，染色预览采用原版颜色与亮度规则，隐形对象以暗色保留可见；尚未移植完整 XNA 透明度预乘、游戏贴图着色器或照明效果。
- 材料面板提供自由绘制、起终点直线、连续折线和方向约束。直线拖动只保留当前端点预览；折线点击续接上一端点，每段为一步历史，拖动超过 2 格后结束续接。折线锚点与悬停连线显示在地图上，Esc、双指、尺寸或绘制参数变化会清除锚点。方向约束按桌面原版的整数规则锁定水平、竖直或 45° 方向。矩形、椭圆、右斜线、左斜线和 X 形画笔可独立设置 1–400 格宽高，也可锁定宽高，或使用 1、3、5、9 格快捷尺寸；偶数尺寸按原版向左上定位。线形粗细为 1 时使用细线；大于 1 时按原版作为圆形扩展半径，上限为短边的一半。任一边为 1 格时按原版使用矩形落笔。光标显示实际图格边界，X 形两臂之间的空格不会被填满。四种轨迹均支持这些笔形、绘制、擦除、选区裁剪和整笔取消，抬起后提交。掩码提供 17 类原版条件（材料、坡形、涂料、制动器、涂层、四色电线、液体种类和液量），可从吸管取样建立全部条件；多个条件同时成立才会编辑。设定来源条件和目标材料后填充选区，即可匹配替换。条件也作用于画笔和擦除，复制/模板/粘贴保持完整区域操作，不使用这些条件。每次操作最多 10000 格。
- 连通填充按桌面原版的材料、墙壁阻挡、坡形、制动器或液体规则寻找四方向相邻区域，支持方块、墙壁、液体、坡形、制动器和涂料层；原版不支持的电线填充保持禁用。点击起点先计算并预览，确认后作为一步历史写入；Enter 确认，Esc、取消按钮、第二指加入或地图尺寸变化取消。可先框选限制范围，起点须在选区内。最多计算 10000 格候选，超限整次拒绝；条件掩码只过滤最终写入，不阻断连通路径，家具保护继续生效。
- 选择方块或墙壁作为编辑图层，使用五种已支持的笔形，宽高可独立设置，也有 1、3、5、9 格快捷尺寸；放大到 200% 以上后绘制，每次拖动作为一步操作。只修改所选层的材料，保留其他层、液体、电线和已有外观状态，跳过家具等依赖帧数据的特殊图格。
- 可分别显示或隐藏方块、墙壁和液体，隐藏前景方块后可以查看其后的墙壁。显示开关不改变存档或撤销历史；隐藏的编辑图层不能绘制或擦除。
- 吸管按编辑图层选取材料，并显示同格的方块/墙壁 ID、涂料、坡面、液体、电线、制动器和涂层属性。目录内材料会自动切换到画笔；空格、特殊图格或尚未支持的材料会提示原因，不改变材料或历史。属性是最近一次取样的快照，编辑后需重新取样。放大到 200% 以上点击使用，拖动或双指浏览不会取色。
- 橡皮只擦除所选编辑图层：方块层会清除方块及其涂料、坡度、制动器等附属状态；墙壁层会清除墙壁及其涂料、隐形和全亮标志。保留另一层、液体与电线。为保护家具及其支撑，擦除跳过特殊图格及其直接相邻（含斜邻）位置；该保护不等同于游戏物理模拟。
- 框选支持正向或反向拖动矩形，显示坐标、尺寸和格数；有选区时画笔和橡皮只修改选区内的格子。可用当前图层的材料填充选区或擦除该层，每次区域操作作为一步历史，继续沿用特殊图格保护。选区本身不修改存档；Esc 取消正在拖动的草稿并保留旧选区，无草稿时清除选区。
- 复制普通图格选区后，点击“粘贴预览”，通过点击、拖动或 X/Y 坐标定位左上角，再确认或取消。聚焦地图时可用 Ctrl+C / Ctrl+V，预览中方向键移动 1 格、Shift+方向键移动 10 格，Enter 确认、Esc 取消。复制和预览不修改存档；粘贴完整替换目标矩形的方块、墙壁、液体、电线和外观状态，**包含空格**，不受旧选区或编辑图层限制，并作为一步撤销历史。
- 复制内容可在关闭世界后保留，用于另一个文件格式版本完全相同的世界；刷新页面后清空，仅保存在本页内存中。每次最多 10000 格，整个粘贴区域必须位于地图内；复制含家具/实体的区域，或粘贴触及家具、实体及其相邻支撑时整次拒绝。该保护不模拟完整游戏物理，跨版本粘贴尚未开放。
- 复制内容可左转或右转 90°、左右或上下翻转，坡面方向随之变化，保留墙壁、液体、电线和外观状态。变换不修改世界；预览时保留左上角坐标，并重新检查目标是否越界。半砖只支持左右翻转，其余变换会产生无法保存的半砖方向，因此整次拒绝并保留原内容。
- 可将复制内容导出为 `.tedit-template.json` 建筑模板，以后重新导入使用。先打开相同文件格式的世界，再导入本项目模板；成功后只更新复制内容，确认粘贴才修改世界。模板最多 2 MiB、10000 格，包含尺寸、格式版本和图格字段，不包含世界名称、实体或历史；仅在本机处理。损坏、跨版本、特殊图格或无法完整保存的数据会拒绝导入，并保留原复制内容。不支持桌面 `.TEditSch` 文件。导出模板不会将世界的未导出修改标记为已保存，仍需单独导出世界副本。
- 撤销与重做，可使用按钮或聚焦地图后按 Ctrl+Z / Ctrl+Y（也支持 Ctrl+Shift+Z）。Esc 取消尚未完成的笔画，触控第二指加入时也会取消该笔并切换为浏览手势。
- 导出世界副本：未编辑时要求重新生成的文件与原文件逐字节一致；首次编辑前检查相同的保真条件，修改后核对世界头、箱子、NPC 等非图格区段及区段位置变化，存在异常时停止导出。
- 首次成功缓存网站后，可以断网打开、编辑与导出文件。存档不会上传，也不会写入网站离线缓存；关闭或刷新页面后需要重新选择文件。存在未导出修改时提示确认，但浏览器被系统终止时无法保证提示生效，请及时导出。

当前读取范围为文件格式版本 194–326，且受上游解析器的标准世界尺寸限制。格式范围不代表所有存档均经过游戏验证。地图支持色块与基础贴图切换：放大到 400% 以上且可见区域不超过 65536 格时，绘制泥土、石块、森林草地和短植物；原版帧选择器已移植，区域合并结果有界计算，未收敛、缺图、其他群系、树木、家具、油漆、液体或坡面等仍回退色块。粘贴预览仍为色块。缩小时使用采样概览，放大可查看单格。单文件最多 4 MiB，单张解码 RGBA 最多 4 MiB，缓存贴图的 RGBA 像素预算合计 12 MiB（不等同整个浏览器进程内存），可取消加载或清除资源。编辑仍处于早期阶段，暂不支持家具、箱子物品编辑或 `.twld` 模组配套文件，游戏内兼容性仍需实际验收。单笔或单次区域操作最多 10000 格，区域面积超限时整次拒绝；历史最多保留 100 步且累计不超过 50000 格修改记录，超过时释放最早的步骤。请保留原始存档，使用更新的浏览器并先测试副本。

## 本地运行

使用 Node.js 22.12 或更新的兼容版本：

~~~sh
npm ci
npm run dev
~~~

构建：

~~~sh
npm run build
~~~

测试：

~~~sh
npm test
~~~

测试首次运行会下载固定上游提交的 7 个世界样例，并验证 SHA-256。样例只保存在本地忽略目录中，不会打包到网站。

项目子目录部署时设置 VITE_BASE_PATH=/仓库名/，仅需托管 dist/，无需服务器端程序。

## 开源来源

文件格式与功能研究参考 [TEdit](https://github.com/TEdit/Terraria-Map-Editor) 和 [TEdit Web](https://github.com/TEdit/terraria-map-editor-web)。世界文件读写通过项目适配层接入 [terraria-world-file-ts](https://github.com/TEdit/terraria-world-file-ts)，固定来源和局部修改见 [vendor/terraria-world-file](vendor/terraria-world-file/README.md)。完整世界留在 Worker 中处理，界面接收基本信息和当前视图的像素数据。
