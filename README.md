# 泰拉瑞亚地图编辑器

[访问网页](https://woshimaxfive.github.io/terraria-editor-zh/)

一个独立实现的泰拉瑞亚网页地图编辑器，目前提供地图浏览、普通方块、墙壁与液体编辑、普通图格区域复制粘贴、建筑模板、家具与实体内容编辑。

## 当前功能

- 在本机浏览器中打开 `.wld`，查看世界名称、尺寸、种子、出生点、难度和对象数量。
- 浏览色块地图；可从本机选择 Tiles_0、1、2、3.xnb 或同名 PNG，在显示面板切换基础地形贴图。资源只在本机读取，关闭世界即释放，不分发游戏图片。支持拖动、滚轮或双指缩放、坐标查看、全图与出生点定位。也可聚焦地图后使用方向键、+ / − 和 Home。
- 编辑工作区采用顶部文件/编辑/图层/帮助菜单、上下文参数、左侧工具、右侧材料/建筑/家具/世界/对象/NPC/显示/帮助面板和底部状态栏。菜单支持方向键、Home/End 和 Esc；手机侧边面板浮动展开，切换面板不挤压地图。
- 材料目录包含 139 种普通方块和 50 种建筑墙壁，支持中文名、英文名、ID 搜索和分类筛选；搜索没有结果时保留当前材料。目录按已验证范围逐步开放，尚未包含所有游戏材料。
- 在编辑图层或材料面板选择液体，可绘制水、熔岩、蜂蜜和微光；液量采用桌面原版 0%–100% 的 11 档，默认满量，0% 清除液体。支持画笔、选区填充、橡皮、选区擦除、吸管及撤销重做，只修改液体种类和液量。吸管按原版向上取最近档位。格式 269 以下不支持微光；跳过特殊家具和实体附近图格。显示使用基础色彩，不模拟游戏内液体流动、反应或家具破坏。
- 电线图层可多选红、蓝、绿、黄：画笔添加选中色线，橡皮只移除选中色线，其他颜色和所有材料字段保持不变。支持连接家具和机关、选区、吸管及历史。制动器图层独立设置是否有制动器及是否虚化，仅作用于已有方块；橡皮同时移除制动器并实化。选择对应编辑图层自动显示标记，放大至 200% 以上绘制简化连线与状态标记，显示面板可分别关闭；不分发游戏贴图，也不在网页模拟电路。
- 坡形图层可设置完整方块、半砖和四向斜坡，只作用于原版支持坡面的已有方块（含平台），橡皮恢复完整方块。涂料图层可分别设置方块/墙壁的 32 种油漆或隐形/全亮涂层，支持家具染色、吸管、选区和历史，保留帧和实体；橡皮只清除当前类型。旧格式禁用涂层，夜明涂料在格式 269 起转换为全亮涂层。放大时显示简化坡形，染色预览采用原版颜色与亮度规则，隐形对象以暗色保留可见；尚未移植完整 XNA 透明度预乘、游戏贴图着色器或照明效果。
- 材料面板提供自由绘制、起终点直线、连续折线和方向约束。直线拖动只保留当前端点预览；折线点击续接上一端点，每段为一步历史，拖动超过 2 格后结束续接。折线锚点与悬停连线显示在地图上，Esc、双指、尺寸或绘制参数变化会清除锚点。方向约束按桌面原版的整数规则锁定水平、竖直或 45° 方向。矩形、椭圆、右斜线、左斜线、X 形、星形、三角、月牙和圆环画笔可独立设置 1–400 格宽高，也可锁定宽高，或使用 1、3、5、9 格快捷尺寸；矩形和椭圆的偶数尺寸按原版向左上定位。线形粗细为 1 时使用细线；大于 1 时按原版作为圆形扩展半径，上限为短边的一半。未启用变换时，任一边为 1 格按原版使用矩形落笔。星形和三角按原版中心定位，月牙的宽控制丰满度、高控制外径，圆环的宽控制环厚、高控制外径；实际范围以光标为准，保留笔形的空洞。月牙 2×3 的原版无效尺寸和过小三角的无图格状态会明确提示，保留当前世界。四种轨迹均支持这些笔形、绘制、擦除、选区裁剪和整笔取消，抬起后提交。掩码提供 17 类原版条件（材料、坡形、涂料、制动器、涂层、四色电线、液体种类和液量），可从吸管取样建立全部条件；多个条件同时成立才会编辑。设定来源条件和目标材料后填充选区，即可匹配替换。条件也作用于画笔和擦除，复制/模板/粘贴保持完整区域操作，不使用这些条件。每次操作最多 10000 格。
- 九种笔形均可绕落笔中心旋转 0–360°，支持左右和上下翻转，先翻转后旋转；重置只恢复角度和翻转开关，保留形状、宽高及线形粗细。光标显示实际图格边界，包括空洞。按原版在角度大于 0.01° 时启用旋转，360° 仍走变换路径，因此部分笔形可能与 0° 的范围不同；变换时单轴尺寸也使用各自笔形规则。过小的空笔形或原版无效月牙尺寸会提示并拒绝落笔，世界和历史保持不变。变换支持四种轨迹、掩码、选区、擦除与历史；参数变化清除折线锚点，绘制中暂时禁用变换控件。
- 方块和墙壁层支持空心画笔：按当前笔形与边框厚度绘制边框、清除内部方块，并可选择内墙材料；墙壁层只处理内部。边框、内部清除和填墙合为一步撤销，内部清除后会重新检查匹配条件，再决定是否填墙。按桌面原版，未旋转或翻转的矩形首印为空心，拖动后续按实心区域延伸。沿用家具及实体附近保护、选区和单笔预算；隐藏墙壁时不能执行跨层填墙。
- 自由绘制可启用喷枪，九种笔形及旋转/翻转均按原版有序印章抽样；密度 1%–100%（默认 15%），间隔 10–100 毫秒（默认 100）。落笔立即喷绘，移动或松开时按累计间隔补采样；整笔去重并作为一步历史。喷枪使用实心笔形，保留空心设置，切回普通画笔后恢复。支持当前编辑层、条件过滤、选区、保护、擦除和整笔取消；指针越过世界边界时按原版夹到边缘后采样。超出单笔格数或计算预算时整笔拒绝，不写入部分结果。
- 世界面板可编辑名称、难度、困难模式、24 小时时间/月相、天气，以及 Boss、事件、居民解锁与增益标记；按存档格式显示可编辑属性。旧格式只提供经典/专家，新格式提供经典/专家/大师/旅行；改名同步文件末尾校验，机械 Boss 进度同步总标记。草稿可跨分类修改、保存为一步共享历史，Esc 或取消恢复；名称最多 1024 字节 UTF-8。修改标记不会重新生成地形或移动 NPC。世界种子文本保持只读。
- 世界属性还包括入侵类型/数量/位置、邪教徒延迟、39 个中文渔夫任务、七种矿物选择、暗影珠计数和相关标记、树木/洞穴分区、108 个背景/树木/洞穴样式选项及按格式存在的特殊种子标记。背景和样式保留原版真实的非连续 ID，未改动的未知值保留。分界点不能越过相邻分界；地层相碰联动 6 格，支持安全范围开关和原版顺序的背景间距修复，草稿期间即时显示联动结果，确认保存后作为一步历史。关闭安全范围仅调整本次地层可用范围，不向存档新增设置字段；改变矿物、邪恶或特殊种子标记不会重新生成地形，背景样式在游戏中生效，当前预览仍使用已有图格渲染。
- NPC 面板支持 60 种原版目录的中文、英文、ID 搜索，以及已有居民的个人名称检索；按存档版本开放添加，在当前出生点创建居民，拒绝新增重复种类。可分别编辑、删除已有的重复实例；支持改名、宠物/动物学家变体、微光外观、派对、无家可归与按格式存在的消失标记。地图定位使用当前位置，点按移动同步当前位置与住所，拖动、双指、Esc 或尺寸变化取消。草稿保存、添加、删除和移动均加入共享撤销历史；微光和派对按种类生效，只改变目标 ID 的成员关系，其他重复、未知或离场 ID 保留。名称最多 1024 字节 UTF-8，不分发 NPC 图片。
- 基本属性可编辑 int32 世界 ID 与标准 GUID，保存及撤销会同步文件末尾校验和页面信息。位置分类可修改主出生点、地牢入口及按格式存在的队伍点，也可选择地图位置工具点按移动；拖动浏览、第二指加入、尺寸变化和 Esc 不会提交未确认的位置。空队伍列表首次启用时按当前草稿出生点建立白、红、绿、蓝、黄、粉六个点，已有条目及未知额外条目保留。每次保存或地图点按作为一步共享历史；仅修改位置数据，不移动建筑、地形或 NPC。
- 对象面板可查找、定位并编辑已有箱子的名称、物品 ID、数量与前缀，以及告示牌的中文多行文本。6170 个原版物品有独立目录，支持中文/英文/ID 查找，6163 项已有中文名称，其余保留英文回退；物品 ID 按存档格式限制，旧格式禁用新召唤词缀。支持原有可变槽数，未改动的未知物品保留。草稿可取消，保存后与图格编辑共用一步撤销/重做；草稿期间其他编辑及导出锁定。对象位置、数量、槽数及家具图格不改变。单字段最多 1 MiB UTF-8，最多编辑 1000 槽箱子，超过历史预算写入前整次拒绝。
- CAD 路由支持 90° 转弯和四连通的 45° 阶梯，自动、先水平或先竖直方向，以及按画笔宽高布置、起始线距两格的总线；纯水平或竖直路径按原版可能合流。支持当前可编辑图层。点按先写一格并设锚点，再点按提交路径，每段一步历史；可开启连续接线。Shift+W 循环关闭/90°/45°，Shift+Q 循环方向；切换模式保留锚点，方向或宽高变化重算预览。Esc 或右键清锚点，再按 Esc 退出模式；已提交首格保留。网页在松手时确认点按，拖动浏览、双指取消尚未确认的点按；材料、图层、匹配条件或地图尺寸变化清锚点。笔形、旋转、空心和喷枪设置保留，退出 CAD 后恢复；沿用选区、掩码、保护与导出校验，超出单段 10000 格或计算预算时整段拒绝。
- 连通填充按桌面原版的材料、墙壁阻挡、坡形、制动器或液体规则寻找四方向相邻区域，支持方块、墙壁、液体、坡形、制动器和涂料层；原版不支持的电线填充保持禁用。点击起点先计算并预览，确认后作为一步历史写入；Enter 确认，Esc、取消按钮、第二指加入或地图尺寸变化取消。可先框选限制范围，起点须在选区内。最多计算 10000 格候选，超限整次拒绝；条件掩码只过滤最终写入，不阻断连通路径，家具保护继续生效。
- 选择方块或墙壁作为编辑图层，使用九种笔形，宽高可独立设置，也有 1、3、5、9 格快捷尺寸；放大到 200% 以上后绘制，每次拖动作为一步操作。只修改所选层的材料，保留其他层、液体、电线和已有外观状态，跳过家具等依赖帧数据的特殊图格。
- 可分别显示或隐藏方块、墙壁和液体，隐藏前景方块后可以查看其后的墙壁。显示开关不改变存档或撤销历史；隐藏的编辑图层不能绘制或擦除。
- 吸管按编辑图层选取材料，并显示同格的方块/墙壁 ID、涂料、坡面、液体、电线、制动器和涂层属性。目录内材料会自动切换到画笔；空格、特殊图格或尚未支持的材料会提示原因，不改变材料或历史。属性是最近一次取样的快照，编辑后需重新取样。放大到 200% 以上点击使用，拖动或双指浏览不会取色。
- 普通橡皮擦除所选编辑图层；空心橡皮按启用的内部填墙设置处理相关层。方块层会清除方块及其涂料、坡度、制动器等附属状态；墙壁层会清除墙壁及其涂料、隐形和全亮标志。普通擦除保留另一层、液体与电线。为保护家具及其支撑，擦除跳过特殊图格及其直接相邻（含斜邻）位置；该保护不等同于游戏物理模拟。
- 框选支持正向或反向拖动矩形，显示坐标、尺寸和格数；有选区时画笔和橡皮只修改选区内的格子。可用当前图层的材料填充选区或擦除该层，每次区域操作作为一步历史，继续沿用特殊图格保护。选区本身不修改存档；Esc 取消正在拖动的草稿并保留旧选区，无草稿时清除选区。
- 复制普通图格选区后，点击“粘贴预览”，通过点击、拖动或 X/Y 坐标定位左上角，再确认或取消。聚焦地图时可用 Ctrl+C / Ctrl+V，预览中方向键移动 1 格、Shift+方向键移动 10 格，Enter 确认、Esc 取消。复制和预览不修改存档；粘贴完整替换目标矩形的方块、墙壁、液体、电线和外观状态，**包含空格**，不受旧选区或编辑图层限制，并作为一步撤销历史。
- 复制内容可在关闭世界后保留，用于另一个文件格式版本完全相同的世界；刷新页面后清空，仅保存在本页内存中。每次最多 10000 格，整个粘贴区域必须位于地图内；复制含家具/实体的区域，或粘贴触及家具、实体及其相邻支撑时整次拒绝。该保护不模拟完整游戏物理，跨版本粘贴尚未开放。
- 复制内容可左转或右转 90°、左右或上下翻转，坡面方向随之变化，保留墙壁、液体、电线和外观状态。变换不修改世界；预览时保留左上角坐标，并重新检查目标是否越界。半砖只支持左右翻转，其余变换会产生无法保存的半砖方向，因此整次拒绝并保留原内容。
- 可将复制内容导出为 `.tedit-template.json` 建筑模板，以后重新导入使用。先打开相同文件格式的世界，再导入本项目模板；成功后只更新复制内容，确认粘贴才修改世界。模板最多 2 MiB、10000 格，包含尺寸、格式版本和图格字段，不包含世界名称、实体或历史；仅在本机处理。损坏、跨版本、特殊图格或无法完整保存的数据会拒绝导入，并保留原复制内容。不支持桌面 `.TEditSch` 文件。导出模板不会将世界的未导出修改标记为已保存，仍需单独导出世界副本。
- 撤销与重做，可使用按钮或聚焦地图后按 Ctrl+Z / Ctrl+Y（也支持 Ctrl+Shift+Z）。Esc 取消尚未完成的笔画，触控第二指加入时也会取消该笔并切换为浏览手势。
- 导出世界副本：未编辑时要求重新生成的文件与原文件逐字节一致；首次编辑前检查相同的保真条件，修改后仅允许已编辑图格及通过字段校验的世界属性、箱子/告示牌、图格实体及 NPC 区段变化；对象、实体、NPC 和世界头尾区段须逐字节等于独立跟踪的期望快照，未批准的头字段、其他对象和居民记录等保持一致，存在异常时停止导出。
- 首次成功缓存网站后，可以断网打开、编辑与导出文件。存档不会上传，也不会写入网站离线缓存；关闭或刷新页面后需要重新选择文件。存在未导出修改时提示确认，但浏览器被系统终止时无法保证提示生效，请及时导出。

当前读取范围为文件格式版本 194–326，且受上游解析器的标准世界尺寸限制。格式范围不代表所有存档均经过游戏验证。地图支持色块与基础贴图切换：放大到 400% 以上且可见区域不超过 65536 格时，绘制泥土、石块、森林草地和短植物；原版帧选择器已移植，区域合并结果有界计算，未收敛、缺图、其他群系、树木、家具、油漆、液体或坡面等仍回退色块。粘贴预览仍为色块。缩小时使用采样概览，放大可查看单格。单文件最多 4 MiB，单张解码 RGBA 最多 4 MiB，缓存贴图的 RGBA 像素预算合计 12 MiB（不等同整个浏览器进程内存），可取消加载或清除资源。编辑仍处于早期阶段，旧式装备家具、压力板配套记录、含家具的区域复制/模板及 `.twld` 模组配套文件尚未支持，游戏内兼容性仍需实际验收。单笔或单次区域操作最多 10000 格，区域面积超限时整次拒绝；历史最多保留 100 步且累计不超过 50000 条等效记录（对象快照按字节计入），超过时释放最早的步骤。请保留原始存档，使用更新的浏览器并先测试副本。

## 家具编辑

- 家具目录含 412 类、9546 种样式，类别有中文标签，支持中文、英文、ID 和样式名称搜索。按世界格式筛选图格，样式保留原版尺寸和存储帧；部分样式名称或变种仍显示原文。旧图格 ID 的新样式不保证在所有旧游戏版本中呈现相同外观。
- 家具工具支持检查与取样完整结构、放置、更换样式和删除。可输入左上角坐标或在地图上点按；预览显示完整清理范围与新家具范围，确认后才写入。替换涉及的旧家具会完整清理，有配套记录或内容丢失时需勾选确认；同起点、同配套类型的箱子或告示牌保留内容，实体还需类型一致。图格与配套记录合为一步共享撤销历史。
- 图格实体内容支持训练假人关联编号、物品框、逻辑感应器、人体模型装备/染料/手持和姿势、武器架、帽架、食物盘、物品瓶及风筝/小动物锚点。晶塔没有额外内容字段。姿势、槽位及物品按原版枚举和格式边界校验，未编辑的未知物品、字段与保留位保持不变。实体草稿期间锁定其他编辑与导出，取消或 Esc 恢复原值。
- 预览取消、拖动浏览、双指或地图尺寸变化不会写入世界。完整结构必须位于世界和当前选区内；不完整、歧义或配套记录异常时整次拒绝。工具遵循原版左上角放置语义，不模拟游戏支撑物理。旧式人体模型/女性人体模型/武器架（128/269/334）、压力板配套替换、家具复制与模板仍待接入；家具显示目前仍使用色块，游戏内兼容性需用副本实际测试。

## 本地运行

使用 Node.js 22.12 或更新的兼容版本：

~~~sh
npm ci
npm run dev
~~~

构建：

~~~sh
npm run build
~~~

测试：

~~~sh
npm test
~~~

测试首次运行会下载固定上游提交的 7 个世界样例，并验证 SHA-256。样例只保存在本地忽略目录中，不会打包到网站。

项目子目录部署时设置 VITE_BASE_PATH=/仓库名/，仅需托管 dist/，无需服务器端程序。
